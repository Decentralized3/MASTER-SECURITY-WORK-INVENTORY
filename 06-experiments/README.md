# Experiments

Experiments are recorded when the process itself produced useful technical knowledge, even if the expected result was not achieved.

## Experiment standard

Each experiment should answer:

**Question → Approach → Observation → Result → Lesson → Next step**

Examples currently supported by the recovered history:

- Android state-machine testing
- Nested Intent / Parcelable testing
- Frida lifecycle-hook experimentation
- Android IPC testing with a custom PoC
- Web/API validation against false-positive hypotheses
- Cloudflare and WAF behavior during authorized testing
- Reconnaissance automation attempts and API/rate-limit constraints

Failed approaches are not hidden, but they are not presented as successful capabilities.
