# Private Work

Some work is technically relevant but should not expose its implementation.

A private record may document:

- the problem
- objective
- safe methodology
- engineering decisions
- testing approach
- result
- lesson
- next direction

It must not expose:

- credentials
- tokens
- cookies
- personal data
- confidential reports
- target-sensitive source
- operational material prohibited by a program
- unpublished vulnerability details

The purpose is to preserve the engineering record without turning GitHub into a disclosure channel.
