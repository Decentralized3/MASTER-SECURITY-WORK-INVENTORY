## JamVoice

Python / GTK / GStreamer real-time voice-processing application.

The work involved:

- voice effects/presets
- audio processing
- noise/dynamics processing
- virtual audio routing
- OBS integration
- Linux PulseAudio/PipeWire
- GStreamer pipeline troubleshooting

The project demonstrates iterative software debugging and engineering, but it is intentionally kept separate from the security narrative.
